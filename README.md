# Logistic-Regression-vs-Naive-Bayes-Medical-Classification

In this project, Logistic Regression and Naive Bayes were trained and evaluated on the same medical dataset.
Naive Bayes achieved better accuracy and precision, but its recall score was lower than Logistic Regression.
Since this is a medical classification problem, recall is particularly important because a low recall score may result in missing patients who actually have the disease (False Negatives).
Based on the evaluation results, Logistic Regression appears more suitable for this dataset when prioritizing disease detection and minimizing false negatives.
However, the final model selection depends on the medical application's requirements and the trade-off between false positives and false negatives.
This experiment demonstrates that a model with higher accuracy is not necessarily the best model for every real-world problem.
